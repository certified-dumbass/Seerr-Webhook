Seerr Discord

Koppel Seerr requests aan Discord en tag gebruikers zodra hun request beschikbaar is.

Schakelt alle Seerr Discord-functionaliteit in of uit.

Optionele beveiliging voor inkomende Seerr webhooks. Gebruik deze waarde als Bearer-token of als X-Seerr-Token header.

Nieuwe requests

Discord webhook die nieuwe Seerr requests ontvangt.
Beschikbare placeholders: {user}, {mention}, {discordUserId}, {title}, {mediaType}, {mediaStatus}, {requestId}, {jellyfinUserId}, {jellyfinMediaId}

Beschikbare requests

Discord webhook die notificaties ontvangt zodra media beschikbaar is.
Gebruik bijvoorbeeld: {mention} jouw request **{title}** is nu beschikbaar!
Gebruikt de gekoppelde Discord User ID voor een echte mention.
Indien uitgeschakeld wordt de beschikbare notificatie overgeslagen als geen Discord User ID gevonden is.

Discord weergave

Jellyfin ↔ Discord gebruikers

Vul bij iedere Jellyfin-gebruiker de numerieke Discord User ID in.
