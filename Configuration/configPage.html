Seerr Discord

Connect Seerr requests to Discord and notify users when their requested media becomes available.

General

Enables or disables all Seerr Discord functionality.
Optional shared secret used to secure incoming Seerr webhook requests. Leave this empty if token validation is not required.

New Requests

Sends a Discord notification when a new Seerr request is created.
Discord webhook that receives new Seerr request notifications.
Available placeholders:
{user}, {mention}, {discordUserId}, {title}, {mediaType}, {mediaStatus}, {requestId}, {jellyfinUserId}, {jellyfinMediaId}

Available Requests

Sends a Discord notification when requested media becomes available.
Discord webhook that receives availability notifications.
Example:
{mention} your request **{title}** is now available!
Uses the linked Discord User ID to create a real Discord mention.
When disabled, notifications are skipped if no Discord User ID is linked.
